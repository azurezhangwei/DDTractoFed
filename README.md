# DDTractoFed

This repository provides the official implementation of DDTractoFed, a federated learning framework based on diffusion MRI (dMRI) tractography for population classification.

## Overview

DDTractoFed is designed for multi-site dMRI tractography-based population studies, where data sharing is often restricted by privacy, ethical, and institutional constraints. The framework enables collaborative model training across multiple sites without requiring direct data transfer.

The proposed method is developed for population-level classification using dMRI tractography data and aims to address inter-site variability caused by differences in subjects, scanners, and acquisition protocols.
